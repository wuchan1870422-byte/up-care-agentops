## 本次发现并修复

1. 缺失 globals.css 导致页面不能构建。
2. Next 内部 localhost 与请求 Host 不同导致合法写入被 Origin 检查拒绝。
3. 质检否定词跨句影响，漏掉“两次康复就能好”；已加入回归。
4. 新会话仍展示上一次 Run；已清空活动上下文。
5. 知识编辑正文缺少稳定可访问名称；已增加 aria-label。
6. 失败后从头重试导致副作用重复；现在沿用原始 Run 幂等键。
7. 受限知识在历史轨迹中泄漏的风险；已过滤相关运行与会话。
8. 服务端 connections 状态覆盖 integrations 记录导致设置页崩溃；已分离字段并在两种存储模式验证。
9. 从咨询跳转到工单后触发按钮已卸载；弹窗关闭后焦点恢复到对应工单行。
10. 模板表单字段缺少稳定可访问名称，已增加明确标签。
