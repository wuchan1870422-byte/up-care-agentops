# 知识检索设计

实际路径：文档 → 650 字符块、500 字符步长 → 英文词和中文二元词分词 → 关键词逆文档频率排序 → 前 5 个命中片段 → 回复引用。

得分是关键词相关性数值，不是语义相似度或回答可信概率。查询无命中时明确表示“不知道”；不以固定问答表冒充检索。管理员新增或编辑内容后立即重新分块，下一次检索使用新版本。

- `documentId + version + chunk` 定位引用；引用快照存入 Run，知识以后变化不改写历史轨迹。
- source 只接受 HTTP(S)，空 source 标为虚构演示政策；链接由用户自行打开，不让服务器任意抓取 URL。
- reviewer 文档不对普通服务角色开放；角色切换后的运行记录与相关对话也必须限制披露。
- active=false 的文档不参与新检索；历史内容保留用于追溯。
- 文档内容是资料，不是系统指令。规则执行器不执行上传内容或其中要求跳过审批的指令。
- 本地支持 TXT、Markdown、文本型 PDF；扫描 PDF 不提供 OCR。公开浏览器模式仅支持 TXT/Markdown，并明确提示限制。

未实现：Embedding 生成、向量库、Hybrid Search 和学习式 reranker。未来采用 pgvector 时，应保留关键词降级，按实际调用记录模型与索引版本，先对引用正确性和访问过滤做回归测试。
