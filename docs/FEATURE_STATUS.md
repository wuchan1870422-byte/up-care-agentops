# 功能状态矩阵

2026-10-09。原始完整范围保留在 MASTER_SPEC.md。这里的“已实现”均指独立概念演示，不等于医疗生产系统。

| 系统 | 已实现与已测部分 | 尚未完成 / 未连接 |
|---|---|---|
| 01 Command Center | 三栏联动、咨询消息、字段、引用、运行轨迹、真实 SSE、工单及审批 | 真实模型推理摘要 |
| 02 Service Agent | 双语规则、多轮补问、偏好更正、服务语言、人工转接、工具参数与权限、幂等、超时、重试 | 可配置真实 LLM Provider 与模型原生工具调用 |
| 03 Quality | 6 类规则风险、具体片段与建议、批量、人工复核；原 Scenario B 全部检出 | LLM 审查、任意知识冲突检测、完整问答覆盖判定 |
| 04 Knowledge | 文档 CRUD（归档式删除）、MD/TXT/PDF 本地上传、分块、关键词检索、来源、版本、访问过滤 | Embedding、向量检索、Hybrid Search、OCR；浏览器 PDF |
| 05 Workflows | A–E 预定义入口；咨询节点历史、条件分支、失败恢复；Coze 服务端封装 | 任意图形编辑、其他流程统一节点轨迹、在线 Coze 验证、后台队列 |
| 06 CRM & Tasks | 虚构联系人/线索/会话/意向/工单/跟进/审核/审计；分配、备注、筛选、CSV | 真实 CRM、排班、消息通道、共享 PostgreSQL、正式用户认证 |
| 07 Follow-up | 多条原文摘录、未解决事项、跟进状态及审核工单 | 真实模型摘要、语义纵向分析 |
| 08 Documentation | 保守 SOAP 草稿、缺失标记、专业审核；不自动填写 A/P | 真实双语模型整理、正式医疗文书集成 |
| 09 Analytics | 日期/院区筛选、真实运行趋势、工单状态、意图、风险、检索命中与处理耗时 | 企业实际 KPI、财务或效率提升报告（无内部数据） |
| 10 Evaluation | 77 个独立虚构案例，真实规则/检索/工具执行；历史结果、耗时、审计；69 项工程测试 | 真实模型评测、模型超时实测、标注集泛化验证、自动版本比较 |
| Advanced | 工单 CSV、节点回放、响应式主题、公开演示持久化 | 语音、Prompt Lab、Mock Appointment API、可编辑流程、正式管理报告导出 |
